## 🚀 Key Projects

### 🐚 [shells](https://github.com/kuarahy/shells)
> *Config-driven React page shells — scaffold once, reuse everywhere.*

A TypeScript npm package that lets you define full-page layouts, forms, and workflows through configuration rather than repetition. Built for teams that are tired of copy-pasting the same shell into every new project.

`TypeScript` `React` `npm` `Component Library` `Config-Driven`

---

### 🧵 [loreweaver](https://github.com/kuarahy/loreweaver)
> *A browser-based storyboard engine for tabletop RPG campaigns and world-building.*

System-agnostic by design — no D&D assumptions, no vendor lock-in. Drop in a `.loreweaver.json` config and get a fully interactive campaign board. Ships with a Forgotten Realms Sword Coast sample. [Live demo →](https://loreweaver-eldenmoor.vercel.app)

`JavaScript` `Vercel` `Tabletop RPG` `World-Building`

---

### 🎲 [Marvel United Randomizer](https://github.com/kuarahy/Marvel-United-Randomizer)
> *Storyline and character suggestions for Marvel United board games.*

A Java CLI tool that randomizes hero/villain matchups and campaign structures for Marvel United. Comes with full campaign files for the Avengers and X-Men arcs.

`Java` `Board Game` `Marvel`

---

### 📡 [kuarahy-streaming](https://github.com/kuarahy/kuarahy-streaming)
> *A local notification system for streamers — no cloud, no subscriptions.*

Go backend proxy + React/Vite frontend that runs entirely on `localhost`. Surfaces live alerts into OBS browser sources without routing anything through a third-party service.

`Go` `React` `Vite` `OBS` `Streaming`

---

### ⚽ [World Cup Table 2026](https://github.com/kuarahy/World-Cup-Table-2026)
> *An interactive HTML page to register and track World Cup results.*

Because filling in a paper bracket like you were 10 years old is still fun — just faster when it's digital.

`HTML` `CSS` `JavaScript`
